# Fonts

PaperDaemon uses Adobe's Source type family: one sans, one serif and one monospace, drawn to work together.
All three are under the SIL Open Font License 1.1, so they may be bundled with the app and redistributed.
Each folder holds the license that came with the font.

| Folder | Font | Used for | Files |
|---|---|---|---|
| `source-sans-3/` | Source Sans 3 | all interface text | variable WOFF2, upright and italic |
| `source-serif-4/` | Source Serif 4 | page titles and section headings | variable WOFF2, roman and italic |
| `source-code-pro/` | Source Code Pro | endpoints, paths, tokens, launch scripts | variable WOFF2, upright |

Downloaded unmodified from the `release` branch of each official repository on 2026-09-26:
